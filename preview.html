Untuk produk seperti itu, saya akan prioritaskan arsitektur yang fleksibel terhadap banyak provider AI dan streaming response.

Fondasi yang saya sarankan
  • Frontend React + TypeScript dengan streaming UI.
  • Server layer untuk mengorkestrasi beberapa provider model.
  • PostgreSQL untuk chat history, workspace, dan metadata.
  • Provider abstraction supaya model bisa diganti tanpa mengubah UI.

Kalau kamu mau, arsitekturnya bisa dibuat lebih spesifik untuk model comparison, web search, files, dan custom skills.
