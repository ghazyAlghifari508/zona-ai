# P9 browser QA evidence

Curated screenshots from the P9 Chrome DevTools review. Selector images are cropped around the model picker; admin images show the model table and its actions. Raw source screenshots included account details, so the account/sidebar area is excluded from published crops.

The full validation results, caveats, and incident disclosure are in [`../p9-handoff.md`](../p9-handoff.md). Raw screenshots, browser snapshots, and logs containing personal or environment-specific data are intentionally excluded. These images are visual evidence, not a substitute for the recorded test results.
