# P8 — Chat History — Vertical Ellipsis

**Kompleksitas:** SMALL — surgical UI change  
**Dependency:** P7 selesai  
**Tujuan:** Eksekusi hanya fase P8 terhadap [Zona.ai](http://Zona.ai), bukan membuat rencana tanpa implementasi.

## Tujuan

Saat hover chat history di sidebar, tombol tindakan saat ini horizontal ellipsis (`...` atau titik tiga tiduran). User menginginkan vertical ellipsis (`⋮` berdiri). Hanya ubah orientasi icon dan bila perlu accessibility behavior untuk menu existing, bukan redesign Sidebar atau penggantian fungsi rename/delete.

Baseline `src/components/layout/Sidebar.tsx` mengimpor `MoreHorizontalIcon` dari `@hugeicons/core-free-icons`, digunakan pada DropdownMenuTrigger history item (size 16, strokeWidth 1.75, hover/focus opacity). Baca HEAD aktual dan cek import sebenarnya; gunakan vertical counterpart yang betul-betul diekspor oleh versi Hugeicons terpasang, jangan mengarang nama icon. Reuse existing shadcn/Radix DropdownMenu, Button primitive jika appropriate dan asset icon library existing. Tidak perlu pasang library UI baru hanya untuk rotasi 3 titik. Component discovery rule tetap berlaku secara proporsional: existing component sudah cocok; cek docs/existing exports dan catat alasan reuse, jangan bikin icon SVG dari nol.

```
SEBELUM                                 SESUDAH
[logo] Checklist Deploy Aplikasi  ...   [logo] Checklist Deploy Aplikasi  ⋮
       18/9/2026                               18/9/2026
```

Preserve menu opens correct conversation ID, rename, delete confirmation, keyboard focus, return focus, hover placement, aria-label, 16px icon scale/stroke token existing. Trigger tidak boleh hilang pada keyboard focus, menu open, atau perangkat touch yang tidak punya hover (tampilkan sesuai media `(hover: none)`/design behavior yang tepat). Jangan gunakan literal text character untuk icon UI bila library menyediakan. Ganti hanya history menu, jangan global-replace ikon horizontal pada komponen lain. Jangan menambah badge/copy baru, layout shift, padding yang membuat nama chat makin terpotong.

## Acceptance

- Existing component and actual vertical icon used, unused old import cleaned jika tidak digunakan di tempat lain. Preserve dropdown action, route and IDs. Component unit tests exercise menu open/rename/delete behavior and accessible label, keyboard/touch logic where deterministic; don't test exact icon markup/className or screenshot until P9. Run typecheck/lint and sidebar-related tests. Commit surgical change. Report exact icon export used and any remaining known issue. No Browser QA here.
