# P5 — Global Dropdown & Chevron Fix

**Kompleksitas:** MEDIUM — shared control dan accessibility  
**Dependency:** P4 selesai  
**Tujuan:** Eksekusi hanya fase P5 terhadap [Zona.ai](http://Zona.ai), bukan membuat rencana tanpa implementasi.

## Tujuan

Perbaiki icon dropdown/select yang menempel di ujung kanan border. User ingin posisi rapi dan konsisten pada seluruh aplikasi, bukan redesign dropdown menjadi control yang lebih kompleks. Baseline native `<select ... px-3>` tidak menjamin padding arrow browser. Lokasi terverifikasi: admin models provider, admin users role/status, admin feedback status/category/change status, admin audit action, admin credits adjustment type, ArtifactHeader version selector. Search repo-wide `<select`, SelectTrigger, Combobox, MenuTrigger, chevrons di routes dan components; periksa juga kontrol baru P2/P4. Bedakan select yang memilih value dari menu aksi dan popover lainnya; jangan mengganti icon menu horizontal di history di sini (P8).

## Solusi

Gunakan shared ready-made component (shadcn Native Select/Select atau HeroUI Select yang kompatibel dengan dependencies; lihat dokumentasi actual). Prioritaskan primitive yang ada; untuk native selection sederhana pertahankan semantik native dengan controlled custom chevron jika komponen siap pakai mendukungnya. Untuk searchable/complex option gunakan Radix/Base UI/React Aria primitive yang memang diperlukan, bukan custom listbox dari nol. Tidak duplikasi CSS dan wrappers per route. Component source references: [https://ui.shadcn.com/docs/components/select](https://ui.shadcn.com/docs/components/select) ; [https://heroui.com/docs/react/components/select](https://heroui.com/docs/react/components/select) ; [https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/select](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/select) ; [https://developer.mozilla.org/en-US/docs/Web/CSS/appearance](https://developer.mozilla.org/en-US/docs/Web/CSS/appearance) ; [https://www.w3.org/WAI/ARIA/apg/patterns/listbox/](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/) . Verifikasi versi.

Untuk native select styled: indicator default dinonaktifkan dengan `appearance: none` bila diperlukan; icon absolute vertically centered, `pointer-events: none`, padding right cukup agar teks tidak overlap; jangan memakai dua chevrons. Pastikan select/trigger yang klikable mencakup seluruh area, bukan arrow-only. Untuk accessible non-native select, gunakan built-in keyboard/open/close/selection/typeahead behavior, focus return dan screen reader. Jangan gunakan DropdownMenu untuk mengganti select value secara salah. Jangan mengubah values/routes/server filter logic, label semantics, keyboard form submit atau disabled state.

Rekomendasi ukuran sesuai kepadatan [Zona.ai](http://Zona.ai): trigger 36–40 px regular, 12 px left padding, 12–14 px right inset untuk chevron, icon 14–16 px, center vertical, text-to-icon gap minimal 8 px. Compact variant untuk toolbar artifact boleh mempertahankan tinggi sebelumnya, tetapi tetap punya inset visual yang memadai. Semantic borders/background/focus ring, light/dark; touch target memadai, no clipping via portal or overflow. Long labels jangan mepet dengan arrow.

Use the existing value copy except planned normalization (mis. Semua provider) and no badge embellishments. For null/disabled/loading keep state actual. Apply to all discovered select controls, not only screenshots. Verify responsive width through code/component contracts now, browser check deferred to P9.

## Acceptance

- Discovery evidence and one reusable control/variants, actual library component used. Inventory each select before/after and exceptions with reasons. No arbitrary new motion/animation/layout.
- Controlled value and onChange fire correctly; keyboard navigation, focus, disabled and labels remain. Filter values sent unchanged, artifact version selects correct version, credits action type and feedback mutation preserve semantics, no duplicate arrow or icon event capturing.
- Accessibility/component tests deterministic (labels, selection, callbacks, keyboard where supported), no CSS className assertions; existing route/component/regression tests pass. Typecheck/lint/build if dependency changed. Note exact desktop/mobile/light/dark visual targets for P9. P6/P7 must reuse this shared component rather than recreate.
